## 1. 初版边界

### 1.1 交付范围

| 范围 | 初版交付 |
| --- | --- |
| 玩家侧 | 个人任务，进度随玩家保存；支持接取、提交、取消进入失败、目标重试和内容入口重新投放 |
| 世界侧 | 共享任务，进度随世界保存；多人状态与操作由主世界服务器授权 |
| 单机 | 两侧完整流程，含进出子世界后继续游玩 |
| 多人 | 个人任务各自推进，世界任务共同推进；中途加入、重连、正常领奖可用 |
| 多人子世界 | 玩家分处主世界与子世界时，进度汇总、操作请求和奖励发放可用 |
| UI | 可用的任务列表与详情页，准确展示状态并提供合法操作 |
| 内容接入 | 两侧各一条可照抄的完整示例，以及对应接入说明和验收记录 |

### 1.2 本版取舍

| 事项 | 本版处理 |
| --- | --- |
| 世界任务整任务重试 | 补齐多人及子世界支持 |
| 玩家任务取消 | 沿用“取消即失败”；重复任务由内容入口移除旧任务、创建新实例 |
| 玩家任务通用整任务重试按钮 | 延后 |
| 世界目标内奖励、未完成的使用物品目标 | 延后 |
| 可视化任务树、星级 | 延后；收起未完成入口 |
| 正式剧情数量、新玩法系统、新美术 | 不作为任务系统初版完成条件 |

运行环境已确认；功能取舍沿用本清单的收尾建议。后续版本的完整范围见第 6 节。

## 3. 功能规则与范围细则

### 3.1 内置目标范围（F03）

| 目标 | PlayerSide | WorldSide | 验收重点 |
| --- | --- | --- | --- |
| 击杀 NPC | `KillNPCObjective` | `WorldKillNPCObjective` | 类型、数量与条件正确；玩家侧区分历史计数/独立计数 |
| 收集物品 | `CollectItemObjective` | `WorldCollectItemObjective` | 玩家侧区分拾取累计/当前持有量；世界侧按任一玩家达标判定 |
| 消耗物品 | `ConsumeItemObjective` | `WorldConsumeItemObjective` | 正确记录物品/弹药消耗，不重复计数 |
| 到达环境 | `ExploreObjective` | `WorldReachObjective` | 到达指定环境后完成 |
| 环境内移动 | `ExploreObjective` | `WorldExploreObjective` | 只累计满足条件的移动 |
| 对话 NPC | `TalkNPCObjective` | `WorldTalkObjective` | 仅指定 NPC 对话触发 |
| 提交物品 | `GiveItemObjective` | `WorldGiveObjective` | 数量/对话条件正确；只扣应扣数量；重试不沿用旧提交标记 |

| 共同规则 | 验收要求 |
| --- | --- |
| 活动范围 | 事件累计型目标只在规定活动期间收集进度；历史计数和背包持有量按各自规则判定 |
| 停止与恢复 | 取消、完成、超时后停止扣物品与事件累计；恢复后不重复订阅或计数 |
| 世界贡献 | 主世界与子世界按目标自身规则汇总；收集物品不能误写成全员背包数量相加 |
| 不支持项 | `UseItemObjective` 标记为禁止使用的 `Obsolete`，不纳入初版 |
| 两侧差异 | 只保证表中现有目标，不要求两侧补齐同名类型 |

### 3.2 生命周期、结构与重试（F01–F06）

| 项目 | 初版规则 |
| --- | --- |
| 玩家接取 | NPC/交互对当前注册的 Available 实例调用既有 Actions；批量入口按自身来源快照候选，不重复创建同名任务 |
| 玩家完成 | 自动完成与手动提交遵守任务配置；完成后发奖并进入正确历史状态 |
| 玩家取消/任务到期 | 进入 Failed，不自动回池；`Reset()` 清进度但不改变状态 |
| 玩家重新获取 | 内容入口移除旧任务，再创建并接取新实例 |
| 目标组合 | 顺序、并行全部、任选其一、分支；只承诺当前节点 API 可表达的组合 |
| 两级计时 | 任务计时独立存在；未激活目标不计时，目标超时只冻结自身 |
| 截止边界 | 同一更新时间片内，目标完成判定优先于目标到期判定 |
| 单目标重试 | 只重置允许重试的当前超时目标；保留其他目标、分支选择和任务总计时 |
| 玩家目标领奖标记 | 目标重试保留已领取标记 |
| 世界整任务重试 | 可重试的失败任务在单机、多人和子世界均有入口；重复请求不重复重置 |
| 不可重试目标 | 不提供误导性的重试入口 |

### 3.3 奖励与已接受的限制（F07）

| 项目 | 初版规则 |
| --- | --- |
| 玩家奖励 | 保留任务奖励与目标奖励；同实例重复提交/目标重试不重复发奖 |
| 新一轮玩家任务 | 内容入口投放的新实例按新一轮任务处理 |
| 世界任务奖励 | 完成后从详情页领取，正常连接时物品实际到账；重复点击/请求不重复发放 |
| 世界目标内奖励 | 本版排除，正式内容及示例不能依赖它提供后继必需物品 |
| 领取身份 | 按 Ordinal 精确比较玩家名；同名共享记录，改名视为新名称，完成后加入者可领取 |
| 持久化 | 保存领取记录，重新加载后继续生效 |
| 断线例外 | 主服授权后记录即生效；此后断线可能未收到物品且无法再次领取 |
| 协议边界 | 不新增 pending、交付确认、补发或记录回滚 |
| 仍属阻塞的问题 | 正常连接下未到账、重复发奖 |

### 3.4 存档与联机（F08–F11）

| 项目 | 验收要求 |
| --- | --- |
| 保存状态覆盖 | 进行中、分支已选、目标超时、任务失败、已完成未领奖、已领奖 |
| 恢复内容 | 状态、累计进度、计时、分支、领取记录；背包/环境派生进度按当前游戏状态重算 |
| 玩家侧领奖状态 | 玩家完成即发奖，不要求存在单独“未领奖”状态 |
| 数据归属 | 玩家数据随玩家、世界数据随世界；切换角色/世界不串任务 |
| 多人授权 | 主服决定权威状态和副作用；只接受当前有效目标贡献 |
| 加入与重连 | 取得当前快照；旧任务实例、过期操作不能覆盖新状态 |
| 子世界 | 贡献可汇总，重试返回权威结果，奖励发到玩家实际所在世界 |
| 专服与重载 | 无客户端图形访问；进出世界和卸载重载不重复订阅、不残留旧 UI |

| 选择切换 | 筛选/切换后不串详情；检查列表、详情及非选中条目 |
| 状态与 NPC 提示 | 与实际状态一致；目标完成/超时后不再误提示 |
| 可读性 | 长文本、多奖励可滚动；窗口、分辨率、UI 缩放变化后仍可阅读操作 |
| 本地化与占位 | 正式界面的按钮、状态、标题、基础提示具备中英文；收起未接线入口 |
