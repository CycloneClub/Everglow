# Phase 4 Plan 01 – Phase Gate + Spawn Helpers + 碧灵鮟鱇 Tracer

## User Story

**As a** Kelp Curtain player, **I want to** meet the creatures that have no finished artwork yet – starting with the lamp-lit ambusher at the bottom of the Death Jade Lake – and have them spawn only inside Yggdrasil, fight, and drop the items Phases 1–2 already implemented, **so that** the layer keeps filling in while the remaining art is being drawn.

> Planner-derived from the ROADMAP Phase 4 `Goal` line ("Ordinary creatures without complete design textures are implemented after the completed-art tranche, with all ordinary-creature behavior integrated against the item drops already classified and implemented in Phases 1–2"). The roadmap goal is not authored in user-story form; this restates it without adding scope (the Phase 1/2/3 plan precedent).

<objective>
Establish the whole Phase 4 chain on one real creature, then hand waves 2–4 a green gate and a shared spawn-predicate seam to expand into: an art-missing creature that loads, spawns only inside the Yggdrasil Subworld at the lake bottom, runs a server-authoritative stealth/reveal state machine, drops two already-implemented Phase 1 items, is recorded in the shared biology matrix, and is gated by a new offline Phase 4 gate.

Purpose: this is the Phase 4 tracer. It targets the phase's three highest-risk unknowns. First, the gate: D-50 names `scripts/check-biology.ps1`, but the Phase 3 script's invariants are frozen by the Phase 3 close-out chain, so the Phase 4 gate must be a new file that reads the *shared* matrix and leaves the Phase 3 script byte-identical (OQ3). Second, the texture-free class shape: no Phase 4 creature has art, so every class relies on `Texture => Commons.ModAsset.White_Mod`, and the region subfolder a class lives in is what determines where its `.png` must later land for tML's default resolution to find it (Pitfall 3). Third, the spawn boundary: `NPCSpawnManager.EditSpawnPool` returns early outside the subworld, so isolation and the three distinct water conditions (`水面上` / `水底` / land) all live in the per-creature `SpawnChance` (Pitfall 1, Pitfall 6). Proving all three once, here, is far cheaper than discovering a main-world leak or a missing-texture load abort after twenty-five classes ship.

The tracer also stands up the phase-wide infrastructure – `04-DEVIATIONS.md`, the Phase 4 gate, and the shared `KelpCurtainSpawnConditions` helper – so waves 2–4 add classes to an already-green gate and an already-decided predicate seam rather than inventing either under deadline.

D-44 (the 21-row scope), D-48/D-49/D-50/D-51 (missing-art handling and the gate's no-missing-texture assertion), D-52/D-53/D-54/D-55 (server-safe layer-gated spawning), D-56/D-57/D-59 (direct drop tables over implemented items) and D-58's "the mod must still build and load" are implemented here. OQ1–OQ5 are recorded here.

Output: `.planning/phases/04-remaining-ordinary-monsters/scripts/check-biology.ps1`, `.planning/phases/04-remaining-ordinary-monsters/04-DEVIATIONS.md`, the 21 reconciled in-scope rows in `03-BIOLOGY.json`/`03-BIOLOGY.md`, `Sources/Modules/Yggdrasil/KelpCurtain/NPCs/KelpCurtainSpawnConditions.cs`, and `Sources/Modules/Yggdrasil/KelpCurtain/NPCs/DeathJadeLake/JadeSpiritAnglerfish.cs`.
