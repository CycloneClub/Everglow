# Phase 1 Plan 03 — Completed-Art Tranche A (Weapons, Ammos, Materials, Accessories) Parity and Class-less Routing

<objective>
Finish D-12 design parity for the tranche-A completed-art items that have a repository implementation target, explicitly route the class-less tranche-A entries out of Phase 1 to Phase 2, and gate the tranche.

Purpose: the phase's end-to-end inventory tracer shipped in 01-01 and the reconciliation record in 01-02. The prior 01-03 execution (Task 1, commit `261996ecf`) reconciled the numeric columns of the tranche-A completed-art classes but halted at its second task because 18 class-less completed-art entries exceeded the plan's own >8 bound. Those 18 entries have complete design artwork but no repository implementation target and a false Feishu design-code checkbox, so the phase baseline forbids force-implementing them here; they are routed to Phase 2. This plan therefore resumes from the committed numeric pass, completes the non-numeric design parity (effects, recipes, set bonuses) the SUMMARY specifically left open (D-12), records the Phase 2 routing, and installs the tranche-A coverage gate.

Output: reconciled tranche-A classes, an inventory with explicit Phase 2 routing for every class-less entry, and `scripts/check-tranche-A.ps1`.
</objective>
