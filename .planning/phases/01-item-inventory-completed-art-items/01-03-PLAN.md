## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Fetched design rows -> C# values | Design text is transcribed into code; it must remain data. |
| Item classes -> build/package pipeline | New/changed classes are compiled and packaged into the .tmod. |
| Repo topology -> file paths | `internal_name` is mapped to a source path; the mapping must not let design text choose a path. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | Placeholder art introduction | high | mitigate | The no-placeholder prohibition plus `check-tranche-A.ps1`'s `.png` git guard; absent art stays a blocker. |
| T-03-02 | Tampering/Elevation | Instruction-like design-row text driving code/paths | high | mitigate | Only numeric/name fields are transcribed; paths are derived from repo namespace conventions and the inventory id, never from document text. |
| T-03-03 | Tampering | Silent omission of a completed-art entry | medium | mitigate | The coverage checker requires every completed-art tranche-A entry to have a class or a blocker. |
| T-03-04 | Denial of Service | Build/resource-packing failure from duplicate or bad assets | low | accept | No new assets are added; the standard build is the check. |
| T-03-SC | Tampering | Package supply chain | low | accept | No packages are installed in this phase. |
