# Phase 1 Plan 04 — Completed-Art Tranche B (Armors, Placeables, Pets, Boosters) Parity

<objective>
Bring the completed-art tranche-B items to design parity and category correctness, using the plan-02 inventory as the worklist, and gate the tranche.

Purpose: the roadmap requires entries with complete design artwork to be usable first, without placeholder assets and without wholesale rewrites of code that already matches (D-10). The 20 tranche-B completed-art entries (`phase == 1`, `tranche == "B"`, `artwork_complete == true`) all already map to repository classes, so this plan is parity plus category correction, not new content. This plan is deliberately sequenced after plan 03 (wave 4, `depends_on` includes `01-03`) because both plans write `01-INVENTORY.json` and both invoke `dotnet build` over the shared `bin/`/`obj/`; the declared edge orders them instead of leaving the shared mutable state implied. The four developer-tool `LocalizationCategory` fixes remain in plan 05, which owns localization classification immediately before the exporter runs.

Output: reconciled tranche-B classes, `LocalizationCategory` overrides for the seven placeable `_Item` classes, and `scripts/check-tranche-B.ps1`.
</objective>
