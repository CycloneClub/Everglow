# Phase 2 Plan 03 — Snake Egg Use Item and the Six Art-Pending Shells (Group A)

## User Story

**As a** Kelp Curtain player, **I want to** hold the quest reward that summons the jungle snake and see every remaining designed item exist as a real item type, **so that** nothing in the design list is silently missing from the mod while its artwork is still being drawn.

> Planner-derived from the ROADMAP Phase 2 `Goal` line. The roadmap goal is not authored in user-story form; this restates it without adding scope (the Phase 1 plan-01 precedent).

<objective>
Implement the ITEM-04 carrier `灵蛇玉卵` and the first group of six identity-only shell classes, so the remaining designed item names exist as loadable types with recorded art blockers while their behaviour stays defined only by the design (D-18).

Purpose: ITEM-03 and ITEM-04 cover exploration/collection rewards and NPC-trade/quest rewards. Six of these entries have a design row with a name and nothing else — no damage, no price, no rarity, no effect — and D-18 deliberately answers that with an identity-only shell class rather than invented numbers. `灵蛇玉卵` is the exception: it has a documented value, rarity, use description and location condition, so it gets a full item identity with the encounter itself recorded as a Phase 7 blocker.

Output: `JadeSnakeEgg`, `BambooStepTalisman`, `BambooWeapon`, `BambooHairpin`, `PeachBranchAmulet`, `PeachBlossomKite`, `PandaPet`, and the seven updated inventory rows.
</objective>
