# Phase 2 Plan 04 — The Four System-Dependent Shells and the Remaining Two Art-Pending Shells

## User Story

**As a** Kelp Curtain player, **I want to** see every remaining designed item exist as a real type in the mod, **so that** the design list is fully represented and the paths that are still being designed are visibly reserved rather than missing.

> Planner-derived from the ROADMAP Phase 2 `Goal` line. The roadmap goal is not authored in user-story form; this restates it without adding scope (the Phase 1 plan-01 precedent).

<objective>
Implement the last six shell entries and close the phase's item coverage: the four shells that imply an unimplemented system (D-19) plus the two remaining art-pending shells.

Purpose: D-19 is explicit that items implying a disciple, skill or regional-crafting system are shell classes only, with a precise blocker naming the missing system, and that the system itself is not implemented in this phase. This plan honours that boundary by giving each system-dependent entry an identity, a family-correct localization category and a blocker that names exactly which system must exist before the entry can become real — and by refusing to build a half-tile for the crafting station.

Output: `AlcoholicDrinks`, `FluorescentHydraStaff`, `DiscipleSword`, `DiscipleVanity`, `SkillBambooSlip`, `RegionalCraftingStation`, and the six updated inventory rows that bring the phase to 21 of 21.
</objective>
